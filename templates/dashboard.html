Incident Response Playbooks

Standard Operating Procedures for all SOC levels.

SOC1: Triage & Initial Analysis

  • Verify alert against Threat Intel.
  • Check user behavior (UEBA).
  • If confirmed false positive: Close.
  • If suspicious: Escalate to SOC2.

SOC2: Deep Investigation

  • Analyze PCAP and Sandbox logs.
  • Determine scope of breach.
  • Execute SOAR auto-containment.
  • If critical infrastructure hit: Escalate to Manager.

SOC Manager: Breach Response

  • Initiate disaster recovery.
  • Notify legal and stakeholders.
  • Revoke global credentials.
